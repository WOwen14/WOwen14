## Engineering approach

- Start with the operator's actual workflow, not an assumed requirement.
- Deliver working software early and iterate through direct user feedback.
- Design for offline operation, limited dependencies, and controlled environments.
- Keep operators in control of consequential automated actions.
- Treat testability, traceability, documentation, and deployment as part of the product.
